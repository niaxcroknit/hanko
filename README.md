# 한코 뜨개방

폭닥폭닥 작은 뜨개 가게를 꾸리는 도트 리듬 타이쿤 게임이에요. 손님 주문을 받아 박자에 맞춰 와다다다 뜨고, 번 코인으로 도안책과 도구를 사요.

- `index.html` 파일 하나로 실행돼요(빌드 없음). 폰은 가로로 돌려서 해요.
- 조작: ↑/F 겉뜨기, ↓/J 안뜨기, ←/A · →/G 꽈배기, E ↗, Z ↙, D/K 왼쪽·오른쪽 탭, Space 멈춤.
- 진행은 브라우저(localStorage `hanko-tycoon`)에 저장돼요.
- 글꼴: 갈무리11(SIL Open Font License), 게임에 쓰는 글자만 넣어 파일 안에 포함.
