# 한코 뜨개방 · 안드로이드 앱

게임 전체(`app/src/main/assets/index.html`)를 앱 화면 가득 띄우는 안드로이드 스튜디오 프로젝트예요. 다른 프로그램을 설치하거나 명령어를 칠 필요 없이 안드로이드 스튜디오만 있으면 돼요.

- 패키지 이름: `com.niaxcroknit.hankoknit`
- 개인정보처리방침 주소: https://niaxcroknit.github.io/hanko/privacy.html

## 1. 실행해 보기
1. 압축을 풀고 안드로이드 스튜디오에서 **File → Open**으로 `HankoKnit` 폴더를 열어요.
2. 처음 열면 스튜디오가 필요한 것들을 알아서 내려받아요(인터넷 필요, 몇 분). 아래쪽에 "Install missing SDK platform" 같은 파란 링크가 뜨면 눌러 주세요.
3. 위쪽 ▶ **Run**을 누르면 연결한 폰이나 에뮬레이터에서 실행돼요.

## 2. 플레이 스토어용 파일(.aab) 만들기
1. **Build → Generate Signed App Bundle or APK → Android App Bundle → Next**
2. 열쇠(키) 파일을 새로 만들거나 갖고 있는 걸 골라요. **.jks 파일과 비밀번호는 꼭 따로 보관**하세요. 잃어버리면 앱을 업데이트할 수 없어요.
3. **release**를 골라 만들면 `app/release/app-release.aab`가 생겨요.

## 3. 플레이 콘솔에 올리기 (비공개 테스트)
1. 새 앱 만들기 → 앱 이름 "한코 뜨개방", 게임, 무료
2. 왼쪽 메뉴 **테스트 및 출시 → 테스트 → 비공개 테스트**(Closed testing)로 들어가요. **내부 테스트(Internal testing)가 아니에요.**
3. 트랙에서 테스터 목록(이메일 12명 이상)을 넣고, 새 버전 만들기에서 .aab를 올려요.
4. 개인 개발자 계정은 테스터 12명이 **14일 동안** 참여해야 프로덕션(정식 출시)을 신청할 수 있어요.

## 게임을 고친 뒤 앱에 반영하기
`app/src/main/assets/index.html`을 새 게임 파일로 바꾸고, `app/build.gradle.kts`의 `versionCode`를 1 올린 뒤(예: 1 → 2) 2번부터 다시 하면 돼요.

## 앱에 들어 있는 것
- 가로 화면, 상단바·하단바 숨김, 하는 동안 화면 안 꺼짐
- 뒤로 가기를 한 번 누르면 "한 번 더 누르면 게임을 닫아요"가 뜨고, 2초 안에 한 번 더 누르면 닫혀요.
- 진행은 폰 안에 저장돼요. 웹사이트 저장과는 따로라서, 옮기려면 설정 → 백업 · 불러오기의 코드를 써요. 앱에서는 "파일로 저장"과 "파일 고르기"도 돼요.
- 패키지 이름을 바꾸려면 `app/build.gradle.kts`의 `applicationId`를 고쳐요. 한 번 플레이 콘솔에 올린 이름은 앱을 지워도 다시 쓸 수 없어요.
