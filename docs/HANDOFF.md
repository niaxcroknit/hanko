## 2. 사용자가 확정한 규칙 (중요, 바꾸지 말 것)

### 화면 구조
- 화면 가운데 = 두 바늘 끝이 교차하는 **판정 지점**.
- **편물은 두 바늘 아래에 전체 폭으로 매달려 있음.** 오른쪽에만 쌓이는 게 아님.
- 왼쪽→오른쪽으로 옮겨가는 건 **지금 뜨는 한 단뿐**. 이번 단에서 뜬 코는 한 칸 위(오른바늘)에 올라가서 편물 윗선에 **계단**이 생김. 이 계단이 진행도 표시 역할.
- **평면뜨기**: 한 단 끝나면 편물을 **뒤집음**(뒤집기 연출 = 프레이즈 끝 숨 고르기). 안면 단에서는 겉면 무늬를 만들기 위해 겉뜨기/안뜨기가 반대로 바뀜(실제 뜨개와 동일).
- **원통뜨기**(미구현, 기획만): 뒤집기 없이 계속 회전. 빠르고 끊김 없는 곡에 어울림. 모자·양말 같은 작품용.

### 기법별 입력과 박자
| 기법 | 입력 | 박자 | 편물 모양 |
|---|---|---|---|
| 겉뜨기 K | ↑ 위로 쓸기 (앞→뒤로 찌르기) | 1박 | V |
| 안뜨기 P | ↓ 아래로 쓸기 | 1박 | 가로 돌기 |
| M1L | **코 사이 가로실**에서 ↗ 쓸기 (앞에서 뒤로 찌름) | **반 박자** | 왼쪽으로 기운 늘림코 |
| M1R | **코 사이 가로실**에서 ↙ 쓸기 (뒤에서 앞으로 찌름) | **반 박자** | 오른쪽으로 기운 늘림코 |

## 3. 현재 구현 요약 (`index.html`)

단일 파일, 바닐라 JS + Canvas 2D + Web Audio. 섹션 순서:
